# assets/

- `logo/` — logo brand (`logo_brand.jpg`; disarankan versi PNG transparan).
- `fonts/<Keluarga>/` — satu folder per keluarga font (Montserrat, Anton, Bebas_Neue, ...). Zip asli di `fonts/_arsip_zip/` (tidak di-commit).
- `music/<mood>/` — musik **bebas royalti**, per mood. Panduan lengkap: [music/README.md](music/README.md).
  Musik trending ditambahkan manual di aplikasi Instagram saat unggah.
- `sfx/` — efek suara transisi (`whoosh`, `thump`, `pop`) **disintesis sendiri** oleh `autoreels/render/sfx.py` (bebas royalti); dibuat ulang otomatis bila dihapus.
